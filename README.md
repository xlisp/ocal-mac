# OCAL 准直仪校准工具 — macOS 版

Windows 版 OCAL 1.32(MFC + OpenCV 3.4 + SkinMagic)的 macOS 移植,不再需要切换系统。

## 运行

```bash
pip3 install opencv-python Pillow   # numpy 随 opencv 一起装
python3 ocal.py                     # GUI
python3 ocal.py --selftest          # 自检(格式/绘图,不需要相机)
```

首次使用摄像头时 macOS 会弹授权框,请允许;没有工业相机时可选 **模拟画面**(棋盘格)调试参数。

**USB 工业相机注意事项**(OCAL 专用 4K 相机):

- 首次打开 AVFoundation 会话可能要几秒,程序是非阻塞轮询(最多 ~15 秒),不会卡 UI 也不会崩溃
- 拔线/断流会在视频窗口状态栏提示"画面中断"
- 控制台的 `AVCaptureDeviceTypeExternal is deprecated` 警告来自 OpenCV 自身,无影响可忽略
- 若打开超时:检查 系统设置 → 隐私与安全性 → 摄像头 是否允许终端/Python;确认没有其他软件(原 Windows 版、会议软件)占用相机
- "摄像头设置"里可换设备编号(0–3)和请求分辨率;分辨率取自**首帧**(比查询接口可靠),未知分辨率按原版行为回退 `config4k.txt`

## 功能(与原版一致)

- 工业相机实时画面(默认 4K 3264×2448,支持 1080P/720P/1K 预设)
- 叠加 **3 个同心圆 + 十字准星**,用于光轴对准/校准
- 每个圆:启用开关、半径、粗细、颜色;准星:启用、长度、粗细、角度(0.1° 步进)
- 圆心 = focus 点(每台设备固定的误差标定值,来自 focus.txt,**只读、不可拖动**);"圆心偏移"复选框(默认不勾)开启后可在其基础上上下/左右微调
- 参数保存/加载,文件格式与 Windows 版**字节级兼容**(已验证往返一致)

## 配置文件格式(逆向 OCAL1.32.exe 确认)

### `config<分辨率>.txt` — 11 个 int,空格分隔,无换行

| # | 含义 | # | 含义 |
|---|---|---|---|
| 1 | 圈1 半径 | 2 | 圈1 粗细 |
| 3 | 圈2 半径 | 4 | 圈2 粗细 |
| 5 | 圈3 半径 | 6 | 圈3 粗细 |
| 7 | 准星 长度 | 8 | 准星 粗细 |
| 9 | 准星 角度(**×0.1°**,如 444 = 44.4°) | | |
| 10 | 圆心偏移 **上/下 (Y)** | 11 | 圆心偏移 **左/右 (X)** |

文件按相机分辨率选择:`config4k.txt`(3264×2448)/ `config1080.txt` / `config720.txt` / `config1k.txt`(1024×768),未知分辨率回退 `config4k.txt`(原版默认)。

### `focus.txt` — 4 个 float,每台设备固定的**误差标定值(只读)**

```
0 0 1616.83 1172.13
```

原版用 `ifstream >> float` 连读 **4 个浮点**,但交替写入 2 个变量,因此**只有后两个值生效**:`fx=1616.83, fy=1172.13`。这就是三个圆和十字的圆心 —— 每台设备标定出的误差点,落在视野中央附近(本机 4K 视野中央为 (1632, 1224))。

**focus.txt 在程序内不可修改**:原版只读不写、没有任何 UI 能挪动它,Mac 版行为一致(点视频窗口无任何反应)。若文件缺失,圆心取当前画面中央 `W/2, H/2`。

### 圆心计算(与原版二进制一致)

```
未勾"启用圆心偏移"(默认):x = fx              y = fy            ← 圆心 = focus 点
勾选:                       x = fx + 左右(v11)  y = fy + 上下(v10)
```

偏移(上下/左右)只是相对 focus 点的**临时微调**,数值保存在 config 第 10、11 个字段;focus 点永远以 focus.txt 为准。

十字准星:过中心、角度 `a = v9/10°` 的两条互相垂直直线,半长 `v7`,端点 `(x ± L·sin a, y ± L·cos a)`,圆/线均为抗锯齿(`LINE_AA`)。

## 差异说明

- 颜色不持久化(原版同样只在内存中),默认 圈1红 / 圈2绿 / 圈3蓝 / 准星白
- 原版准星粗细在 UI 层钳制 1..4,Mac 版放宽到 1..10(文件格式不受影响)
- 视频显示为独立窗口缩放预览(原版是 SkinMagic 桌面叠加)
